SPIRIT MIRROR — PASS 10: HAUNTED PORTRAIT

Built directly on Pass 9. Face/jaw fit, front/rear camera handling, and the Reactive Lens Engine remain intact.

NEW IN PASS 10

- High-resolution 1080 x 1620 portrait renderer using the live camera frame, current fitted mask, reactive Lens Engine state, and aged-glass treatment.
- Capture uses the already-smoothed tracked face state at shutter time rather than re-running MediaPipe during export.
- Correct selfie mirroring and rear-camera orientation are preserved in exported portraits.
- Shutter/glass flash feedback after capture.
- In-world Haunted Portrait preview screen.
- RETAKE, SAVE, and SHARE actions.
- Native Web Share API with PNG file sharing when supported; save/download fallback otherwise.
- Optional subtle MIRROR MASK • BOOGEYMAN STORIES signature.
- Client-side only: portraits are generated locally in the browser and are not uploaded by the widget.
